# Dusty's Ganjaria

A time-management game set in a legal dispensary. Customers order, you check their ID, weigh, roll and package
each order, and every order gets a score for speed and accuracy. In early development; nothing is playable yet.

## Install
Local only, with no release. Once the game exists, `Build Ganjaria.bat` makes a Dusty's Ganjaria shortcut on the
Desktop and in the Start menu; start the game from that shortcut.

## Usage
Nothing to use yet.
